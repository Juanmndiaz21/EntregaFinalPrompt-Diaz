# ⚡ Asistente de Dimensionamiento Eléctrico con IA

Aplicación web desarrollada en Streamlit para asistir al personal de comercios de materiales eléctricos en el dimensionamiento de circuitos, cables y protecciones para tableros eléctricos.

## 🚀 Características
- **Procesamiento de Lenguaje Natural:** Permite ingresar pedidos informales expresados en texto libre.
- **Salida Estructurada:** Genera automáticamente la distribución de circuitos, calibre de cables en mm² y llaves térmicas recomendadas.
- **Formato Listo para Cotizar:** Devuelve una lista resumida de insumos requeridos.

## 🛠️ Tecnologías
- Python 3.10+
- Streamlit
- Google Gemini API (`gemini-1.5-flash`)

## 💻 Instalación Local (Windows)
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv venv`
3. Activar el entorno: `venv\Scripts\activate`
4. Instalar dependencias: `pip install -r requirements.txt`
5. Configurar la API Key: `set GEMINI_API_KEY=tu_api_key_aqui`
